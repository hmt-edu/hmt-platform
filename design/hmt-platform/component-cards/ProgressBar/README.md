Thanh tiến độ có nhãn và giá trị bằng chữ: mặc định `hmt-secondary` (CRM, Teacher), `variant="lms"` dùng `hmt-lms-progress`.

- `role="progressbar"` + `aria-valuenow`/`aria-valuetext`; giá trị luôn hiển thị bằng số ("18/32 buổi").
- Không dùng ProgressBar cho trạng thái (đạt/không đạt) hay để biểu diễn điểm số so sánh.
