# Lời nhắn cho Claude Design

Bản sao các prompt anh Trường dán cho Claude Design, để mở tài khoản hoặc chat mới vẫn có đủ. Dán `P5-brief-chung.md` trước, rồi dán file riêng của phân hệ (P5a, P5b, P5c, P5d). `P4-v2` và `P4-bo-sung-ma-cu` dành cho chat P4.

File ở đây là **bản làm việc**; khi một phân hệ xong và vào repo thì ghi trạng thái ở `docs/nhat-ky/design.md`, không sửa tay các prompt cũ trừ khi Claude Chat cập nhật.
