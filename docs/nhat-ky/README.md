# Nhật ký phối hợp

Ba file, mỗi file một bên: `chat.md` (Claude Chat), `design.md` (Claude Design), `code.md` (Claude Code).

**Quy tắc**
- Tối đa **một trang**. **Viết đè**, không viết nối dài thêm; cái gì đã xong và đã vào repo thì xoá khỏi nhật ký.
- Chỉ ghi chữ: không khoá, mật khẩu, dữ liệu thật (tên, SĐT học sinh, phụ huynh).
- Mỗi file có bốn mục: **Đang làm**, **Đã chốt (chưa vào repo)**, **Đang chờ ai**, **File và link mới**.
- Ngày giờ ghi theo giờ Việt Nam. Mỗi lần cập nhật ghi ngày giờ ở đầu file.
- Claude Chat không ghi lên GitHub: soạn nội dung, anh dán cho Claude Code đưa vào repo trong PR tài liệu kế tiếp. Claude Design đẩy lên nhánh `design/…` (xem mục 13 của `docs/quy-trinh-phoi-hop.md`).
- Đầu mỗi phiên, đọc cả ba file.
